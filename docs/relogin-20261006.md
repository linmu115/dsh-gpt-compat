# 账号卡片内重新登录（2026-10-06）

候选版本：GPT Compat 0.6.0-dsh02.3；Accounts 保持 0.1.4-dsh02.4；宿主保持 DSH 0.2.0-rc.2。

登录认证失效时，账号卡片直接提供“重新登录”，包括当前代理账号。入口复用现有 login / loginStatus 接口，登录链接和等待状态留在目标卡片。重复发起在等待期间禁用；此操作不删除账号，也不切换固定代理。

认证失效既可以来自账号状态，也可以来自针对该账号的额度查询。登录回调完成后重新读取账号列表，并核查目标账号额度。只有目标仍存在且核查通过，才显示额度核查结果；不会把回调完成写成模型请求已恢复。失败、超时或登录了其他账号时，保留目标提示与重新发起入口。

未固定代理账号的旧模式会禁用账号内重新登录并说明需要先选择代理账号，避免现有登录接口的旧模式暂停行为被隐式触发。全局新增账号流程保留。

验收分为组件回归、发行包与依赖检查、真实页面按钮检查及受控登录响应交互。真实 OAuth 登录须由用户在浏览器完成，不能以受控响应测试代替真实账号恢复验收。
