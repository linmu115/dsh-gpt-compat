title: 保留会话图片并打通引用预算与图片压缩
status: current
summary: 缺少图片计价接口不能等同于不支持图片；GPT 路线需要真实发送图片并覆盖压缩与恢复。
---

来源：2026-09-17 当前维护任务。用户取消过滤图片方案，询问 DSH 图片发送与 GPT 适配插件的压缩；随后明确批准“先让 Core 的预算策略兼容 DSH，再给 GPT 适配插件补齐图片输入、图片预算和含图片压缩的验证”，并要求继续执行。

- 原始会话图片及用户草稿必须保留；不以删附件绕过预算错误。
- Core 无 route pricing 时采用有余量的中性估算；已声明但无效的计价结果仍拒绝。
- GPT 普通生成、原生计数、压缩及检查点接续均支持图片。工具返回的图片也计入。
- 图片字节仅在发送边界读取；会话投影保存持久引用。压缩成功后旧图可由摘要接续，原始附件留在历史。
- 取消、读取失败、超限或压缩失败不能提交不完整检查点。
- 自动测试、真实模型合成图验证与用户真实会话验证分开报告。
