# GPT 兼容设置页与 DSH 样式统一

用户要求：插件设置页的 UI 展示风格与 DSH 统一（2026-09-17，原页面截图）。

设置入口仍是模型设置页的 `settings.models.footer`。按钮、输入框和添加图标复用 DSH 平台提供的 `@deepseek-ai/dsh-client-ui-primitives`；布局对照 DSH `ModelsSection.module.css`，使用相同的主题变量、字号、边框与圆角。模型列表允许换行，完整展示较长的绑定内容。没有新增运行时配置或修改绑定匹配规则。

CSS 内嵌在经典脚本模块中，通过 Cordis effect 注册并在卸载时撤回，仅作用于 `.gpt-compat-settings`。共享组件来自宿主平台模块表，不引入第二份 React 或通过功能插件跨界导入组件。

## 验证

- TypeScript 类型检查和客户端经典脚本构建通过。
- 现有两项表单测试通过，覆盖按原修订保存，以及保存冲突后保留草稿。
- 在运行中的 rc.2 副本页面验证实际模块加载、16px 标题和卡片圆角、唯一的样式注册，以及编辑后放弃修改恢复原值。
- 使用已加载的 DSH 主题样式检查浅色、深色外观；深色验证仅修改独立浏览器的主题呈现属性，不改用户持久设置。
- 单独将插件容器设为 320px 检查无横向溢出；这不代表 DSH 整个设置弹窗已支持手机布局。
