# 账号认证提示与诊断样式修复（2026-10-06）

候选版本：GPT Compat `0.6.0-dsh02.2` / Accounts `0.1.4-dsh02.4`。宿主继续使用 DSH `0.2.0-rc.2` 的既有 `gpt-dsh02.1` 独立构建。本说明随候选包冻结，实际安装与验收以工作区本轮回执为准。

用户反馈账号显示“暂不可用”，诊断卡正文比标题大且字段排列松散。实际只读检查发现 CPA 正常运行、问题账号为 `error / unauthorized`，该账号的额度查询返回 `401 / token_expired`。协议与 CPA 标识检查通过不能证明账号认证有效。原实现只暴露不可用布尔值，因此隐藏了可归类的认证失败原因。

账号视图增加可选的白名单认证失败原因，前端提示重新登录；旧响应仍可显示通用不可用提示。额度查询的上游 401 与 CPA 管理接口认证失败分别处理。未知失败保持未知，不显示为额度归零，不透传原始错误正文或凭据。登录和固定账号选择仍由用户显式操作，失败不切换账号。

诊断区统一字号和行距，标签与结果分列，窄容器退回单列；模型能力详情、段落间距和键盘焦点沿用插件主题。样式仅作用于诊断区。

本修复不续签账号令牌、不变更固定账号、默认模型或上下文模式，不重建宿主，也不修改外置 CPA。账号恢复需要用户重新登录；提示修复和 UI 验收不能替代账号恢复证明。
